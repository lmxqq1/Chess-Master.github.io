♟ 棋大师 · 开发者接入示例

三种接入方式的可运行代码：iframe 嵌入 / JS SDK / URL 参数启动
文件放置：把 棋大师.html 与本文件放在同一目录，下面的嵌入示例即可直接运行。 若放在 CDN，把代码里的 QM_URL 换成你的实际地址即可（跨域 iframe 的 postMessage 通信不受同源限制影响）。

方式一：iframe 嵌入 推荐

零依赖、样式隔离、跨域可用。宿主页面通过 postMessage 发送指令，通过 message 事件接收棋局动态。

等待棋大师就绪…

宿主页面代码

<iframe id="frame" src="棋大师.html?embed=1"></iframe>

<script>
const frame = document.getElementById('frame').contentWindow;

// ① 发送指令（指令白名单见下方表格）
function send(cmd, arg, opt){
  frame.postMessage({ __qm_cmd: cmd, arg: arg, opt: opt }, '*');
}
send('start', 'gomoku', { mode:'pve', level:2, players:2 });
send('hint');
send('undo');

// ② 接收棋局事件
window.addEventListener('message', e => {
  const d = e.data;
  if (!d || !d.__qm) return;
  switch (d.__qm) {
    case 'ready':        console.log('棋大师就绪', d.data.version); break;
    case 'start':        console.log('开局', d.data); break;
    case 'move':         console.log('落子', d.data);  break;
    case 'finish':       console.log('终局', d.data);  break;
    case 'roomcreated':  console.log('房间码', d.data.code); break;
    case 'result':       console.log('指令返回', d.cmd, d.data); break;
    case 'error':        console.warn('出错了', d.data.msg); break;
  }
});
</script>

支持的指令

指令参数说明
startarg=棋种id, opt={mode,players,level}直接开局
openarg=棋种id只打开设置页，等用户操作
hint / undo / restart / home—对局控制
state / status / games—读取局面与棋种列表
joinRoomarg=邀请码, opt=昵称加入联机房间
setThemearg='dark' | 'light'切换配色

不在白名单内的指令会被拒绝并返回 error，宿主无法借接口越权操作内部 DOM。

方式二：JS SDK 同页面

用 <script src> 引入后，页面内会出现全局对象 window.QiMaster，可直接调用。适合需要深度集成、自定义外壳的场景。

（会打开棋大师自身，控制台预置了调用示例）

调用示例

<script src="棋大师.html"></script>
<script>
// 列出全部棋种
QiMaster.games().forEach(g => console.log(g.id, g.name, g.seats));

// 开一局中国象棋（人机，高级 AI）
QiMaster.start('chess', { mode:'pve', level:3 });

// 订阅事件
QiMaster.on('move',  e => console.log('落子', e.data));
QiMaster.on('finish',e => console.log('终局', e.data));
const off = QiMaster.on('start', e => console.log('开局', e.data));
off();   // 取消订阅

// 读取当前局面
const st = QiMaster.status();   // { game, turn, turnName, over, winner, text }
const full = QiMaster.state();  // 含 board 原始数据

// 联机
QiMaster.on('roomcreated', e => console.log('房间码', e.data.code));
QiMaster.createRoom('gomoku', { players:2 });
QiMaster.joinRoom('ABC123', '玩家昵称');

// 读取账号快照（不暴露任何凭据）
QiMaster.account();  // { login:true, nick, mask:'138****8000', stat:{...} }
</script>

方式三：URL 参数启动 最简单

无需写 JS，拼一个链接即可直达指定棋种与模式，适合做菜单跳转、分享卡片、二维码内容。

棋大师.html?game=gomoku&mode=pve&level=2&auto=1

参数说明

参数取值说明
game棋种 id打开指定棋种的设置页
auto / start1跳过设置页直接开局
modepve / pvp / hot / solo / eva对局模式
players各棋种支持的人数对局人数
level1 / 2 / 3AI 棋力
room6 位邀请码打开后自动加入联机房间
name字符串配合 room 使用，指定昵称
embed1嵌入模式：隐藏外壳与首页文案
chrome1嵌入模式下仍保留顶栏
themedark / light配色

示例：棋大师.html?game=chess&mode=pve&level=3&auto=1 —— 打开即是一局高级 AI 的中国象棋。

事件一览

事件触发时机数据
ready嵌入模式加载完成{ version }
start开局{ game, mode, players }
move每步落子后{ move, state }
finish终局{ winner, text, ... }
result战绩计入{ result:'win'|'lose'|'draw' }
roomcreated联机房创建完成{ code }
joined加入联机房成功{ seat }
error出错{ msg }

用 QiMaster.on('*', fn) 可订阅全部事件。

关于账号：账号数据存在用户浏览器 localStorage 中，没有服务器、不同步。 QiMaster.account() 只返回昵称、脱敏账号与战绩，不暴露手机号/邮箱原文与密码摘要。 若你部署了自己的后端，可在 QM.account 中把 register / login 改为调用你的接口。
